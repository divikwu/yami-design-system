# ActivityPageHeader

Compact mobile navigation for campaign, theme and editorial landing pages.

Use a short title that can remain on one line between the fixed brand and
action groups. The component selects the approved EN or CN Mobile Logo-UI
asset; do not replace it with separately assembled logo artwork.

The Figma source defines only the 56px mobile form. A consuming responsive page
should keep its established global navigation on desktop instead of scaling
this bar up.
