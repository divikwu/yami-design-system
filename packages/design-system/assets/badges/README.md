# YAMI Badges

Y-monogram marks on a flag-shape container (right-side notch). Used as tier / category badges — distinct from canonical brand logos in [`../logos/`](../logos/), which use the disc container and brand red.

## Files

| File | Fill | Token equivalent |
| --- | --- | --- |
| `flag-cap-blue.svg`   | `#005CC2` | `--color-blue-700` |
| `flag-cap-purple.svg` | `#531EE3` | `--color-purple-700` |

26×20 each. Same Y monogram path as `../logos/yami-icon-*.svg`.

## Notes

- Not currently exported from the Figma `品牌 Brand` page — these predate the current brand spec.
- Use case: member-tier markers or product-class flags (per owner).
- Color is non-brand-red — these are NOT subject to the [`red-usage`](../../DESIGN.md) rule. Pick the colour that fits the tier / category semantics (blue / purple are the only two currently provided; add more by following `flag-cap-<color>.svg` naming).
