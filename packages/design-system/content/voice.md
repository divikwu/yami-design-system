# YAMI Voice

Tone derived from the brand's commerce-native, bilingual, spec-led positioning. YAMI speaks to Chinese-American consumers who value clarity over personality, speed over decoration.

## Voice attributes

- **Direct, action-oriented, commerce-native**
  - Calls to action are verbs first: 立即购买 / Buy Now, 加入购物车 / Add to Cart, 提交订单 / Submit
  - Never: "Click here to proceed to checkout when you're ready"
  - Always: "立即结算 · Checkout"

- **Low cuteness, zero emoji**
  - Product UI contains no emoji
  - No "friendly" mascot language ("Oops!", "Hooray!")
  - Error messages are factual: "库存不足 · Out of stock", not "😢 We're so sorry..."

- **Spec-led**
  - Use "必须 / 不得 / 可以" (must / must not / may)
  - Avoid softeners: "尽量 / 建议 / 最好"
  - Every content decision has a functional reason; no copy for "atmosphere"

- **Semantic before decorative**
  - Copy must have a functional purpose
  - Delete any sentence that doesn't answer "what / when / why / how"

## Voice is NOT

- Playful (that's a different brand)
- Aspirational-luxury (reserve "discover / curated / thoughtfully-crafted" language)
- Apologetic ("sorry, we couldn't...")
- Pedagogical ("here's what you need to know about...")
