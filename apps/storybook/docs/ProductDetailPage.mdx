## 共用规则 / Shared behavior

- PC 与 Mobile 使用同一组件，响应式布局在 1024px 切换；工具栏控制内容语言。
- 品类差异由数据决定：护肤品保留多规格选择，食品及饮料展示各自的规格、赏味期限和已核实的食用说明。
- 内容最大宽度由 `contentMaxWidth` 控制；Header、Footer 和全宽分隔线不受此内容宽度限制。
- 商品信息是演示快照，并非实时价格、库存或履约承诺。购物车及评价操作不执行真实交易。

The shared component handles responsive layout, media navigation, quantity controls and disclosures. Product-specific facts remain in independent fixtures; prototype actions do not place orders or submit reviews.
